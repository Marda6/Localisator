ENCY LOCALIZER — ПРОТОТИП

1. Распакуйте архив целиком.
2. Откройте localisator.html двойным щелчком.

Автономная версия: установка программ и интернет не требуются.

ЛОКАЛЬНЫЙ СЕРВЕР (для стабильного сохранения правок)

Нужен Node.js или Python 3.
  Node:    npm start           (или node start_local.mjs)
  Python:  python3 start_local.py
Адрес: http://127.0.0.1:8080. Остановка: Ctrl+C. Другой порт: --port 8081.

РАБОТА С КОДОМ

Исходники в dist/. После правок пересоберите автономный файл:
  npm run build

ДАННЫЕ

Строки, компании и участники демонстрационные.
Изменения сохраняются в браузере, а не в файлах.
Автоперевод работает по демонстрационному словарю.
Экспорт .lng демонстрационный, совместимость с ENCY требует проверки.

Подробности в README.md.
