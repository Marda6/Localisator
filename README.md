# ENCY Localizer

Интерактивный веб-прототип локализатора ENCY / Tuner по ТЗ и отзывам тестировщиков.
Интерфейс собран на дизайн-системе **ENCY Core**: токены, плотность и компоненты те же, что в приложении ENCY.

Живая версия: https://marda6.github.io/Localisator/

## Запуск

Быстрый просмотр: откройте `localisator.html` двойным щелчком. Работает без установки и интернета.

Локальный сервер (нужен Node.js 18+ или Python 3):

```sh
npm start
```

или `python3 start_local.py`. Адрес: http://127.0.0.1:8080. Другой порт: `--port 8081`.

Проверки и пересборка автономного файла:

```sh
npm run check
npm test
npm run build
```

## Что внутри

**Переводы.** Слева дерево приложений по группам с процентом готовности и тумблер «Мои» (только строки, за которые отвечаю я). В центре список строк: эталон, перевод, модуль, ответственный, статус. Поиск по ключу, тексту, переводу и ответственному. Фильтры по статусу и типу модуля (формы VCL, XML, смарт-подсказки). Справа инспектор строки: ключ, приложение, модуль, ответственный, флаг Ignored, эталон, поле перевода с проверками, контекст (схема окна), совпадения, история.

**Проверки при применении.** Параметры `%s`, `%d`, `%1$s`, `{name}` по количеству и типу. Число переносов строк. Контакты, сайты, телефоны и названия дилеров. Орфографию подчёркивает браузер.

**Одинаковые фразы.** Кнопка «Перевести так же ещё N строк» применяет один перевод ко всем строкам с таким же эталоном. Автоперевод предлагается для строк без перевода и получает статус Autotranslated.

**Прогресс.** Карточки по языкам и матрица «приложение × язык». В процент входят только Translated. Ignored исключены из знаменателя.

**Экспорт.** В `.lng` попадают Translated и Outdated. Автоперевод, пустые и Ignored не экспортируются.

**Администрирование.** Компании и доступ к языкам (many-to-many, отметки прямо в таблице). Добавление языков и приложений. Копирование переводов между приложениями по ключу ресурса. Перенос 17.0 → 18.0 с сохранением статуса или Outdated при изменении эталона. Исключаемые модули (например `GR32_portable`).

**Руководство.** Пять шагов, статусы, логика переноса версий, контракт публичного API для перевода из интерфейса ENCY/Tuner.

Роль переключается в шапке: администратор или переводчик одной из компаний. Это демонстрация прав, не механизм безопасности.

Горячие клавиши: `/` поиск, `J`/`K` строки, `Ctrl+Enter` применить, `Shift+Enter` перенос строки в переводе.

## Границы прототипа

Статический прототип без сервера. Все строки, компании и имена демонстрационные. Состояние хранится в localStorage браузера. Автоперевод берёт варианты из подготовленного словаря, внешняя модель не подключена. Формат `.lng` демонстрационный (INI-подобный, UTF-8 BOM, переносы экранированы), совместимость с ENCY требует эталонного файла.

Иконки временно контурные глифы в стиле Core. При подключении Figma их следует заменить на SVG из наборов `icn_inspector` и `Filters icons` файла Core.

Следующий этап: API, авторизация, серверная проверка прав, реальные снимки окон, определение автора строки по истории репозитория, уведомления разработчикам.

## Структура

- `dist/index.html`, `dist/styles.css`, `dist/app.js` — интерфейс.
- `dist/data.js` — демонстрационный корпус 28 приложений.
- `dist/core.js` — валидация, статистика, экспорт, миграция.
- `dist/assets/fonts` — Inter.
- `tests/core.test.js` — проверки правил.
- `localisator.html` — автономная сборка (`npm run build`).
- `start_local.mjs`, `start_local.py` — локальный сервер.
- `.github/workflows/pages.yml` — проверка и публикация `dist/` на GitHub Pages.
